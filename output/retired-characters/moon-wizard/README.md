# Personagem retirada do jogo

A personagem loira com lua no chapéu foi substituída pela personagem flutuante em aquarela.

`Character02/` e `Character02.meta` foram movidos de `UnityProject/Assets/_Game/Resources/Art` para esta pasta. Os dados foram preservados, mas não são mais carregados ou empacotados pelo jogo. As fontes e revisões antigas continuam em `output/new-wizard` somente como histórico.

A personagem atual usa `Art/FloatingWizard` e `CharacterType.FloatingWizard`. Não execute os importadores históricos de `new-wizard` para atualizar a personagem atual.
